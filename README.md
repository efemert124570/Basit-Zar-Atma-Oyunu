#  Zar Atma Oyunu

Bu proje, 1-6 oyuncu arasında oynanabilen, her oyuncunun rastgele bir zar değeri (1-6) attığı ve en yüksek zarı atan oyuncunun kazandığı basit bir zar atma oyunudur.

##  Özellikler

- 1-6 oyuncu desteği
- Rastgele zar değeri üretimi (1-6)
- Geçersiz girişlerde hata mesajı
- Zar atma animasyonu (1 saniye bekleme)

##  Kullanılan Yazılım Dili

- C Dili

##  Derleme

```bash
gcc main.c
```
## Çalıştırma   

```bash
./a.out
```
